# run-run brand

The Sign of run-run: two equal squares, one shifted from the other, for running again. It isn't two rules or a fox.

| File | Use |
| --- | --- |
| `sign.svg` | The Sign, 24×24, in `currentColor`. Sites and images use this file. |
| `sign-readme.svg` | The Sign on a `ground` square, for READMEs. |

How a Sign is drawn and used: [vlab-brand › Project brand](https://github.com/withvariablelab/brand/blob/main/skills/vlab-brand/project-brand.md).
