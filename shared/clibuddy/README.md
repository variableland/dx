# clibuddy

`@variablelab/clibuddy` holds the helpers that [run-run](https://github.com/withvariablelab/dx/tree/main/run-run/cli) and [vland](https://github.com/withvariablelab/dx/tree/main/vland/cli) build their CLIs with: running shell commands, reading packages and workspaces, the task board, and terminal colors and text. It is published because `@rrlab/cli` and `@variablelab/vland` depend on it, and it isn't meant for use outside them.

## Install

```sh
pnpm add @variablelab/clibuddy
```

It needs Node 22.18 or later.
